# Heirloom web app (Next.js PWA)

This folder is the Heirloom web app. The project overview, architecture, how Tether USD₮ + WDK are used, and setup instructions live in the root [README](../README.md).

Quick start (demo mode, no keys needed):

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # unit tests
```
